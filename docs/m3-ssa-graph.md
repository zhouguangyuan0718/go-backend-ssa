# M3 原生 SSA 图与缓存

本步保留 Go 1.27.1 的完整 `Config / Func / Block / Value / Cache` 声明，以及字段所需的寄存器分配、栈分配、调试状态、HTML writer、循环、稀疏树、偏序和稀疏映射声明。类型来自固定源码声明选择，没有重新定义图结构或删减后端字段。`abt.T` 和其节点声明作为调试状态的依赖迁入。

迁入的可执行方法包括原生 `Config.NewFunc`、`Func.NewBlock`、全部 `Block.NewValue*` 构造方法、参数/控制值操作、边的添加/索引交换/移除，以及 `Cache.Reset`。方法体保持原生算法；本步没有增加手写生产适配器。已有 `Types` 的 universe 归属保持不变。

## 生命周期

原生 `Cache` 的值/块数组直接承载图节点。`Reset` 会清空这些节点，因而使旧图失效。这是原生缓存复用契约，不通过复制图或改写 `Reset` 隐藏。后续面向保留图的库入口必须为仍然存活的图保留其缓存；本步并发测试采用每图独立缓存，并同时检查先前创建的 32 位图。

## 验证

`TestPinnedSSAGraph` 在 Go 1.27.1 和 1.27.0 上运行相同原生快照，分别使用 386、amd64、mips、ppc64 布局。对照内容包括：

- 完整图和辅助类型的字段名称、字段类型、嵌入属性和标签；类型显示仅规范化模块路径。既有 `Types` 所有权字段会改变物理大小，因此不将结构字节偏移当作兼容目标。
- 四块分支/合流图、原生值编号/类型/位置/引用计数、控制值、平行边和自环、边交换及移除后的反向索引。
- 全部值构造方法的参数和 Aux 行为，以及参数增长超过内嵌存储后的引用计数。
- 跨越 200 个块和 2000 个值的缓存数组边界、清空缓存、重新建图。

`TestNativeGraphConstructionIsolation` 在 race detector 下并发创建八个独立 64 位图，同时保留一个 32 位图；检查边的双向关系、引用计数、类型归属和节点身份。`TestNativeCacheLifetime` 明确验证缓存重置使旧节点失效以及复用时编号重启。

## 尚未实现

本步没有迁入 `NewConfig` 的架构 rewrite 函数闭包、完整 `Func / Block / Value` 方法集、优化流水线、寄存器分配执行或源码到 SSA 驱动。快照中的 `Config` 字面量仅为原生建图方法提供测试输入，不充当架构工厂。相关类型暂未加入公开 facade，待配置工厂和图生命周期入口具备完整契约后再公开。

仍需接入原生 ssagen 前端、编译器回接以及 build/bootstrap 验证，不能将基础建图差分通过解释为已能替换上游编译器。
