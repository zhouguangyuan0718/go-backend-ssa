# M3 原生哈希与相等比较函数生成

本批完整迁入固定 Go 1.27.1 的 `reflectdata/alg.go`，保留原生算法选择、相等签名、函数 IR 生成和闭包数据写入。没有为哈希或相等操作定义另一套图模型。

## 入口和状态归属

公共 `reflectdata.Context.EqFor` 保留原生入口语义：AMEM 类型返回 runtime.memequal 并指示需要长度参数；ASPECIAL 类型返回按签名生成的相等函数。调用前在所绑定的 typecheck 实例上初始化原生 runtime 声明（InitRuntime）。其他算法类别遵循原生调用前提，不将 EqFor 扩展为适用于任意类型的分发接口。

私有 genhash/geneq 生成原生闭包符号和函数，供后续类型描述符写入使用。它们保持私有；本批公开能力通过已有 EqFor 获得。函数仍登记在同一 typecheck.Target.Funcs 中，后端可以直接消费原生 ir.Func。

memhashvarlen/memequalvarlen 缓存进入已有 reflectdata.Context；类型符号缓存、Link 符号表和生成函数列表沿用所属实例。eqSigBuilder 只是一次调用的临时存储，保留完整原生结构，仅给其需要编译状态的私有 build 方法传入 Context。调试输出复用 IR.TraceWriter，未设置时丢弃，不写进程 stdout。

生成过程沿用原生 DeclFunc/FinishFuncBody/WithFunc，恢复当前函数和函数栈。hashFunc/eqFunc 按原生实现设置 AutogeneratedPos；本批不改变它们对当前源码位置的行为，也不承诺恢复所有调用环境。不同实例可并发工作，同一实例的这些可变操作仍需串行。

## 原生行为

哈希和相等算法保留目标布局、可合并内存读取能力、结构体 padding/空白字段、字符串、接口、数组循环和展开规则。相等签名的编码、解析与函数复用均来自上游；内存闭包保留捕获长度，函数指针重定位保留 ABIInternal。不可比较类型的私有 geneq 仍返回 nil。

本批生成的是经过原生 typecheck 检查的 IR 函数以及闭包的 LSym 字节、属性和重定位。尚未生成或执行这些函数的机器码，也未提供完整类型描述符、ITab 或源码到 SSA 的入口。

## 验证

- 两种指针宽度与允许/禁止合并读取组合，检查函数体、循环、runtime 调用、闭包内容与 ABI、重复生成身份和当前函数恢复。
- 并发创建十二个独立实例，检查符号缓存、调试输出与旧实例函数图和闭包保活；跨实例类型和无效签名按预期失败。
- 独立 consumer 只通过公共包调用 EqFor，检查返回原生函数、函数列表登记、缓存复用和 AMEM 的长度参数契约。
- 固定上游差分覆盖 386、amd64、mips、ppc64，比较算法签名、生成函数的声明及逐节点 IR、闭包字节、全部重定位和原始符号属性。
- 原生 eqSigBuilder 的完整声明逐项对照，确保没有加入多余的归属字段。
