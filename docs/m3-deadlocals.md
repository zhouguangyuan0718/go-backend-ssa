# M3 原生 deadlocals

本批整体迁入 Go 1.27.1 `deadlocals/deadlocals.go`，保留上游文件、包名和 visitor 算法。执行顺序为 pkginit → ABI wrappers → deadlocals → escape；后续 escape、slice、walk 和 SSA 尚未接通。

## 状态与对外入口

`deadlocals.NewContext(graph)` 仅绑定已有 `ir.Context`。`Funcs([]*ir.Func)` 在修改前验证每个函数归属；参数属于其他编译实例时拒绝执行。原生 visitor、定义映射和确定性遍历顺序仍由每次函数调用局部持有，没有加入新的 IR 或优化模型。

迁移规则将 Flag、Debug、AutogeneratedPos、类型表、BlankNode 和 IR 构造/符号/调试操作接到该 IR 实例。原生 `-N` 与 `NoDeadLocals` 跳过条件保留。AST 调试输出使用已有 `IR.TraceWriter`，没有文件输出或进程全局状态。独立图可并发；同一图上的修改由调用方串行。

```go
ssagen.NewContext(reader.Typecheck).NewSymABIs().GenABIWrappers()
deadlocals.NewContext(reader.Typecheck.IR).Funcs(reader.Typecheck.Target.Funcs)
```

规则在 `internal/port/rules_deadlocals.go`，生成文件在 `internal/deadlocals/deadlocals.go`，手写适配在同目录 `adapter_context.go`。工具版本为 `syncgo-m3-v16`，共 258 个迁入文件。既有生成文件仅更新工具版本头，无迁移引擎修改，也没有新增配置文件。
