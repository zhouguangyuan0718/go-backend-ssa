# M7：实例化原生调试参数解析器

迁移固定 Go 1.27.1 的 `objabi.NewDebugFlag`、`DebugFlag.Set` 和帮助格式，不另写参数解析算法。各次解析拥有自己的字段表、SSA 回调和帮助输出缓冲区。

宿主边界将原生显式退出转为局部控制流：帮助返回完整文本并停止后续设置；无效整数、bisect 模式或 SSA 参数返回错误。仅接收该解析器的退出标记，未知 panic 继续传播。普通字段、字符串、bisect 匹配器、重复设置、冒号/等号语法以及 `ConcurrentOk` 规则均保持原生行为。

验证覆盖字段覆写、空字符串、SSA 回调的四项参数、无效输入、帮助排序、帮助后停止、未知 panic 和 12 次并发解析隔离。使用官方 Go 1.27.1 的 `go tool compile -d=help`，完整帮助文本逐字节一致。

全库 `go test -race ./...` 通过；生成文件一致性检查验证 491 个文件。本提交先完成内部解析器；源码 API 与真实驱动的调试状态、报告及文件提供器接入属于下一步，当前不据此宣称整个 `-d` 工作流已验收。
