# M3 源码到原生归档

公开 `compiler.Compile(context.Context, Request)` 接通源码、显式依赖归档、原生前端、SSA、AMD64 指令生成、整包收尾及完整归档输出。每次调用创建独立编译实例；生产代码不启动外部编译器。当前入口固定 Go 1.27.1，仅接受 Linux/amd64 和 GOAMD64 1–4。

输入包含具名源码、包路径、目标实验、依赖归档及导入映射，可选原生 symabis 和嵌入文件提供器。默认、禁用内联/优化和禁用 DWARF 均接入原生标志语义。运行时/标准库标志可以显式设置，但完整标准库编译和自举尚待验证。源码路径用于位置身份；内部逻辑根固定为 `/`，不读取宿主工作目录或环境配置。

返回值包含独立归档字节和结构化诊断。输入在调用期间不得并发修改，依赖归档复制到实例内。错误和取消不返回部分归档；取消在同步阶段边界检查，后端 worker 退出后才返回。未知内部或提供器 panic 保留原值，不伪装成源码诊断。

## 原生阶段与默认值

驱动依次执行源码加载、包名 DWARF 记录、后端配置、覆盖率修正、`PrepareFrontend`、`CompileDeclarations`、`FinishPackage`、归档输出和 `CheckPackage`。最后一项从固定 Main 连续抽取 `CheckLargeStacks`、`CheckFuncStack` 与未编译队列检查；所有检查成功前归档只保留在内部缓冲区。

原生 `ParseFlags` 中从 `Debug.ConcurrentOk` 到 `Debug.Checkptr` 的完整默认值区间迁入实例初始化。生成器新增包变量赋值结构锚点，拒绝局部遮蔽、复合赋值和重复锚点；不手写第二套默认值。实验配置也使用固定上游解析器。

`-dwarf=false` 保留原生位置/行号编码器，同时关闭变量调试信息回调和抽象函数 fixup。指令 Flush 仅在启用变量调试信息时要求相应回调，修复此前无条件检查导致的 panic。

## 验证

- 八个并发源码编译实例，包含泛型依赖、方法、map 初始化、四 worker、默认/禁用优化/禁用 DWARF、依赖输入修改后的旧结果保活。
- 语法、类型、缺失依赖、超大函数栈帧和位置诊断；起始及提供器中取消；嵌入大文件、提供器错误和 panic 保留。
- 固定官方 Go 1.27.1 的真实编译/链接/执行测试：默认、`-N -l`、`-dwarf=false` 三种模式中，依赖和主程序的完整归档均逐字节一致。使用官方链接器和官方 runtime 依赖归档，实际执行库编译的两包程序；goroutine/channel、接口、泛型、map、循环闭包、defer/recover 输出均为 `14 8 6 11`，并与官方编译程序一致。
- 本次 Linux/amd64 执行使用已有 Docker 镜像 `goallc-x86-frame-debug-env:local`，关闭网络、只读挂载临时输出；这项测试由 `GO_SSA_NATIVE_EXECUTION=1` 启用，非 Linux/amd64 宿主另需 `GO_SSA_LINUX_AMD64_IMAGE`。
- 全量 `go test -race -timeout 30m ./...` 通过；新增源码回归最终单独竞态复跑通过；468 个生成文件一致性复查通过。
- Go 1.27.1 / Go 1.27.0 的底层整包管线共 28 组完整归档差分通过，覆盖原有 ABI、优化、DWARF、四 worker、map outlining 和分离归档配置。公开源码入口及真实执行验证当前固定 Go 1.27.1。

## 后续边界

此入口运行完整原生后端；独立使用所需的 Built/EarlyOptimized API 仍需在共享阶段上实现。当前还没有把官方 cmd/compile 驱动切换到本库，也未完成标准库重建或自举。下一步将此入口接到隔离 Go 1.27.1 的真实编译驱动，继续补齐驱动选项、PGO、汇编/cgo 配套输出、第二目标和规定回归。原生 symabis 输入描述 ABI，不代表本入口已经处理汇编源文件或组装归档中的外部对象。
