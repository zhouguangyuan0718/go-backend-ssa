# M3 SSA 数值辅助操作

迁入原生整数、布尔、浮点、ValAndOff、opcode、flag 和 ARM64 参数的 AuxInt 编解码。保留 ARM 位域及条件参数构造/查询、32/64 位算术和逻辑标志位计算，以及所有 flag 条件查询。`truncate64Fto32F` 及其 `isExactFloat32` 依赖也直接迁入，保留 NaN 尾数处理和有损截断的原生 panic。

上述函数没有新增实例状态或手写算法替代；移植规则仅选择原生声明。它们服务于后续 Value 格式化、Aux 查询和 rewrite 规则，当前并不等价于已经迁入完整 rewrite 或 SSA verifier。`check.go` 本阶段仅选择浮点精确性查询。

## 验证

`TestNativeFlagsAgainstUnboundedArithmetic` 使用 math/big 的无界有符号运算、模归约和区间检查，独立求出 N/Z/C/V。输入包含符号和位宽边界及 128 个确定性随机数，按全部输入对检查 32/64 位加减；对减法还检查有符号和无符号比较。期望值不重复原生的定宽溢出公式。

`TestPinnedSSANumeric` 在 Go 1.27.1 和 Go 1.27.0 中分别对照原生行为，按类别比较完整记录流的 SHA-256：整数转换和全部输入对的算术标志、256 种 flag 编码的条件查询、浮点位模式和精确截断、全部合法 ARM 位域、全部合法 ARM64 条件/4 位 NZCV/5 位立即数组合，并记录非法输入的原生 panic。浮点样例含正负零、无穷、不同 NaN 尾数、次正规数边界和非精确值。

这些是固定宽度的纯计算，原生对照仅在宿主进程执行，不重复四种目标布局，也不主张 ARM64 指令执行验证。全仓库 race 测试与生成一致性检查同时执行。
