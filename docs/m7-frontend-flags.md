# M7：原生前端选项

完整 Go/test 的前一轮验证中，16 个叶子用例在 `-live`、`-l=4`、`-B` 或 `-smallframes` 入口停止。接通后，两个活跃性用例又显露出 `-wb=false` 依赖；本次一并接入。

公开选项分别为 `LivenessReport`、`InliningLevel`、`BoundsCheckMode`、`SmallFrames` 和 `DisableWriteBarrier`。内联与边界检查保留原生计数值；已有 `DisableInlining` 保持级别 1 的别名，歧义组合在编译前拒绝。

内联计数转换与小栈帧限制直接抽取自固定版本 `gc.Main`，在保存原始 DWARF flags 后、解析源文件前执行。原生活跃性报告仍使用实例输出和原生后端并发限制。每次编译独立持有设置，不修改进程全局变量。

已验证：

- amd64/arm64 各 15 组原生编译器对照，覆盖默认、内联 1/2/3/4/-1、边界检查 1/2/-1、活跃性 1/2、小栈帧、写屏障关闭及组合选项。完整归档与报告逐字节一致，race 检查通过。
- 组合选项对照同时约束 DWARF producer 中 flags 的原生排列顺序。
- ARM64 上游定向测试官方/替换各 17 项通过、0 跳过（16 个叶子用例及父测试），381 个包记录到本库。

原生 AMD64 同一定向套件官方/替换各 17 项通过、0 跳过，383 个包记录到本库。全库 `go test -race ./...` 通过；`syncgo check` 验证全部 491 个生成文件与固定源码、迁移规则一致。
