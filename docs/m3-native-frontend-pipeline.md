# M3 原生包前端阶段顺序

`gc.Context.PrepareFrontend(symABIs, profile)` 直接抽取固定上游 `gc.Main` 中从首个 `MatchAstDump(fn, "start")` 循环到 `reflectdata.WriteBasicTypes()` 之前的连续区间。算法、分支和阶段顺序保留原生源码：IR 报告、B.Loop、交错去虚拟化/内联、方法包装、循环捕获、初始化任务、ABI 包装、死局部变量、逃逸分析、slice 优化、捕获日志和 runtime 写屏障递归信息收集。

调用者在加载本地 IR、应用覆盖率修正、绑定同一包与已初始化后端后调用一次，再调用 `CompileDeclarations`。PGO profile 和 SymABIs 必须属于同一实例。前端开始前验证函数、全局声明、初始化函数、导入包和导入初始化任务的归属。阶段中途失败会禁止后续编译与收尾，避免输出部分结果。已有显式逐阶段使用方式仍可调用原有编译队列入口。

## 源码抽取

生成器允许同一个原生函数提供多个具名连续区间。每个副本在抽取前从原始字节建立，统一解析到一份位置表，保留词法对象和注释位置；原生函数和副本的选择互不影响。边界可以定位含有指定包调用的完整 `range` 或 `if`，并校验精确字符串参数。结尾可排除定位语句。账本记录原始函数、结构边界和输入签名来源。

仍拒绝模糊锚点、缺失调用、局部捕获、跨区间局部使用、闭包、defer/go/return、递归和输入存储修改。回归覆盖独立阶段执行、并发实例、完整 if/range、原生注释归属及拒绝路径。
